# Dashboard de Controle de Locação de Veículos

Este repositório apresenta um projeto de **Dashboard em Power BI** desenvolvido durante o curso da Udemy, com foco em gestão de frotas e locação de veículos.  
O objetivo é oferecer uma visão estratégica para otimizar operações, controlar custos e apoiar decisões baseadas em dados.

## Principais Funcionalidades
- **Visão da Frota:** veículos por marca e modelo  
- **Gestão de Clientes:** perfil e impacto no faturamento  
- **Performance Financeira:** faturamento total, períodos e ticket médio  
- **Controle Operacional:** situação dos veículos e detalhes das locações  
- **Previsão e Tendências:** projeção de demanda e otimização da frota  

## Tecnologias Utilizadas
- Power BI (visualização e dashboards)  
- SQL (consultas e manipulação de dados)  

## Como Visualizar
1. Instale o Power BI Desktop  
2. Clone este repositório ou baixe o arquivo `.pbix`  
3. Abra no Power BI Desktop e explore os visuais
